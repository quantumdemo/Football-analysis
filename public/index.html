System Overview

The Football AI Intelligence System is an end-to-end probabilistic forecasting platform operating strictly on objective statistical evidence, non-gambling web research, and probability calibration.

Non-Negotiable Constitution Rules

  • Probabilistic Outputs Only: Calibrated probability distributions ($P(H) + P(D) + P(A) = 1.0$). Zero profit or win guarantees.
  • Zero Club Reputation Features: Team names are treated strictly as string identifiers. Prestige and badge value are excluded.
  • Exclusion of Betting Lines: Bookmaker odds, betting lines, and tipster picks are strictly prohibited from predictive models.
  • Explicit NO_BET Abstention: Triggers NO_BET / INSUFFICIENT EVIDENCE on weak, stale, or conflicting data.

Serverless API Endpoints

GET /api/health

Returns operational health status and database metrics.

GET /api/status

Returns system stage completion matrix (Stages 0–25 PASS).

POST /api/predict

Generates auditable pre-match probabilistic report.

POST /api/cleanup

Executes 6-hour automated research cache retention cleanup.
